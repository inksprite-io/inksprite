# inksprite

inksprite is a writing app that runs locally, either in your browser or as a desktop application.

## Running it

```bash
cd app
npm install
npm run dev
```

`npm run build` writes a static site to `app/dist/`. A build sends no
analytics unless it is built with `VITE_VERCEL_ANALYTICS=true`.
