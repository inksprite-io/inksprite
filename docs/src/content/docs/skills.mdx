A skill is a piece of work with instructions of its own: summarizing a chat,
writing a scene, reviewing a draft. You call one by typing `/` and its name in
the chat. The model can be offered a skill too, and calls it when its
description fits what you asked.

## The built-in skills

**Compact**, `/compact`, summarizes the chat to carry on from. Only you call
it; see [Compact a long chat](/chats/#compact-a-long-chat).

## Call a skill

Type `/` at the start of a line in the message box, and the
[list](/chats/#commands) shows every command and skill. Keep typing to narrow
it, press <kbd>Tab</kbd> to finish the name, type what the skill needs after
it, and send. The sparkles mark skills that call the model; they take as long
as a reply does.

When the model calls a skill, its reply shows a block for it. Click the block
to see what the skill was asked, the tools it used, and what it answered.

## Make your own

Open **Settings** › **Skills** and click **New skill**, the plus beside the
heading. A skill is three things:

- **Name**: what you call it, such as *Short Story Editor*. Its command is the
  name in lowercase with hyphens, `/short-story-editor`.
- **Description**: what it does and when to use it. The model reads this to
  decide whether to call it.
- **Instructions**: what the model is told to do. What you type after the
  command goes at the end, or wherever the instructions say `$ARGUMENTS`.

Click the check to save it, or the X to leave it as it was. A skill that can't
be used yet says why under its instructions.

A skill belongs to the app, not a project, so its command works in every chat.
Whether the model is offered it is up to each chat's **Tools**, where your
skills are listed under **Skills**; the Roleplay profiles start with them off.

### Example: a review skill

This skill critiques a draft as an editor would.

1. In **Settings** › **Skills**, click **New skill**.
2. Fill it in:
   - **Name**: *Review*
   - **Description**: *Critique a draft the way an editor would: what works,
     where it drags or loses the reader, and the one change that would help
     most.*
   - **Instructions**:

     ```md
     You are an editor reading a draft for its writer. Read the document
     named below, all of it, before you say anything.

     Then write a short critique:

     - What works, in two or three sentences.
     - Where the pace drags or the reader could get lost, quoting the lines you mean.
     - The one change that would help most.

     Don't rewrite the draft, and don't praise what doesn't earn it.
     ```
3. Click the check.

In a chat, type `/review` and the document's path. To get the path,
right-click the document in the outline, choose **Copy link**, and paste it
after the command.

```
/review Manuscript/Prologue
```

The model reads the document and replies with the critique. Since the model
can call the skill too, *what do you think of chapter 3?* can reach it.

### The file

A skill is kept as a SKILL.md file, the format Claude, Codex and other tools
read. **Open in editor**, beside **Instructions**, opens the whole file in a
tab. The review skill is:

```md
---
name: review
description: >-
  Critique a draft the way an editor would: what works, where it drags or loses
  the reader, and the one change that would help most.
---

You are an editor reading a draft for its writer. …
```

Two lines there say who can call a skill:

- `disable-model-invocation: true` leaves it to you alone.
- `user-invocable: false` leaves it to the model alone.

To delete a skill, open it and click **Delete**. Turns that used it keep what
it said.

## Import and export skills

Click **Import skills**, the arrow beside the heading in **Settings** ›
**Skills**, and choose **Files or a .zip…** or **A folder…**. inksprite finds every SKILL.md in what you choose, and any
Markdown file with frontmatter of its own. Skills made for Claude or another
tool that reads SKILL.md files import as they are.

**Import skills** lists what it found. Switch off any you don't want, then
click **Import 1 skill**, or however many it says.

- **Replaces your…** means you have a skill by that name, and this one takes
  its place.
- A name the app already uses has to change before the skill can come in; type
  a new one in the field under it.
- A skill whose file doesn't read says what's wrong with it, and stays out.
- **Not used here** lists fields in the file that inksprite ignores, and **Left
  out** what it didn't bring, such as scripts.

**Export**, in a skill's card, saves that skill as a file. It imports into inksprite,
or into another tool that reads skills.

## Reword a built-in skill

A built-in skill is worded for each [profile](/chats/#profiles). With a chat
on the profile showing, open **Settings** › **Skills**, click the built-in
skill, and change its **Instructions**. They save as you type, for every chat
on that profile, and the list marks the skill **reworded**. The reset button
beside **Instructions** puts back the wording the profile ships with. The
Roleplay profiles ship with **Compact** worded for games.
