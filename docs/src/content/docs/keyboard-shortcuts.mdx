title: Keyboard Shortcuts
description: The keyboard shortcuts in inksprite, for the editor, the chat, the outline and comments, and the desktop app's keys for tabs and windows.
---

In a document, <kbd>⌘</kbd> <kbd>/</kbd> (<kbd>Ctrl</kbd> <kbd>/</kbd> on
Windows and Linux) lists the editor's shortcuts in the app.

## Anywhere in a project

| Action | Mac | Windows and Linux |
| --- | --- | --- |
| Find in the document or chat you're in | <kbd>⌘</kbd> <kbd>F</kbd> | <kbd>Ctrl</kbd> <kbd>F</kbd> |
| [Search the project](/editor/#search-the-project) | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>F</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>F</kbd> |
| [Focus mode](/editor/#focus-mode) | <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>F</kbd> | <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>F</kbd> |
| Print the open document | <kbd>⌘</kbd> <kbd>P</kbd> | <kbd>Ctrl</kbd> <kbd>P</kbd> |

With a find or the search open, <kbd>Enter</kbd> goes to the next match,
<kbd>Shift</kbd> <kbd>Enter</kbd> to the one before, and <kbd>Esc</kbd> closes
it. <kbd>Esc</kbd> leaves focus mode too.

## In the desktop app

These work only in [the desktop app](/desktop/). In a browser the same keys
belong to the browser, for its own tabs and windows.

| Action | Mac | Windows and Linux |
| --- | --- | --- |
| New document | <kbd>⌘</kbd> <kbd>N</kbd> | <kbd>Ctrl</kbd> <kbd>N</kbd> |
| New chat | <kbd>⌘</kbd> <kbd>T</kbd> | <kbd>Ctrl</kbd> <kbd>T</kbd> |
| Close tab | <kbd>⌘</kbd> <kbd>W</kbd> | <kbd>Ctrl</kbd> <kbd>W</kbd> |
| Reopen closed tab | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>T</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>T</kbd> |
| Next tab | <kbd>⌃</kbd> <kbd>Tab</kbd> or <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>]</kbd> | <kbd>Ctrl</kbd> <kbd>Tab</kbd> or <kbd>Ctrl</kbd> <kbd>Page Down</kbd> |
| Previous tab | <kbd>⌃</kbd> <kbd>⇧</kbd> <kbd>Tab</kbd> or <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>[</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Tab</kbd> or <kbd>Ctrl</kbd> <kbd>Page Up</kbd> |
| First to eighth tab | <kbd>⌘</kbd> <kbd>1</kbd> to <kbd>8</kbd> | <kbd>Ctrl</kbd> <kbd>1</kbd> to <kbd>8</kbd> |
| Last tab | <kbd>⌘</kbd> <kbd>9</kbd> | <kbd>Ctrl</kbd> <kbd>9</kbd> |
| [Projects…](/projects/#switch-projects) | <kbd>⌘</kbd> <kbd>O</kbd> | <kbd>Ctrl</kbd> <kbd>O</kbd> |
| Settings | <kbd>⌘</kbd> <kbd>,</kbd> | <kbd>Ctrl</kbd> <kbd>,</kbd> |
| [New window](/desktop/#more-than-one-window) | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>N</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>N</kbd> |
| Close window | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>W</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>W</kbd> |
| Paste without formatting | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>V</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>V</kbd> |

The tab keys work on the panel you're in: the editor's tabs, or the chat's.
The outline counts as the editor, and the chat list as the chat.

- **Reopen closed tab** brings back the tab you closed last in that panel,
  then the one before it.
- While a dialog is open, such as the settings, only the window keys and
  paste work.
- On Windows and Linux the menu bar is hidden until you press <kbd>Alt</kbd>.
  The keys work either way.
- A [terminal](/terminal/#keys) keeps some keys for its shell.

[Format as you type](/editor/#format-as-you-type). In a table,
<kbd>Tab</kbd> and <kbd>Shift</kbd> <kbd>Tab</kbd> move between cells: see
[Tables](/editor/#tables).

## Chats

| Action | Mac | Windows and Linux |
| --- | --- | --- |
| Send | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| New line | <kbd>⇧</kbd> <kbd>Enter</kbd> | <kbd>Shift</kbd> <kbd>Enter</kbd> |
| Add as user, without asking for a reply | <kbd>⌘</kbd> <kbd>Enter</kbd> | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| Add as assistant | <kbd>⌥</kbd> <kbd>Enter</kbd> | <kbd>Alt</kbd> <kbd>Enter</kbd> |
| Stop a reply | <kbd>Esc</kbd> | <kbd>Esc</kbd> |
| [Find in the chat](/chats/#find-in-a-chat) | <kbd>⌘</kbd> <kbd>F</kbd> | <kbd>Ctrl</kbd> <kbd>F</kbd> |
| Save a message you're editing | <kbd>⌘</kbd> <kbd>Enter</kbd> | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| Cancel the edit | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

In the message box, `/` at the start of a line lists the
[commands](/chats/#commands), `@` [attaches a document](/chats/#attach-documents),
and `[[` links one.

## The outline

Click a row, or move to it with <kbd>Tab</kbd>, and then:

| Action | Mac | Windows and Linux |
| --- | --- | --- |
| Move up or down | <kbd>↑</kbd> <kbd>↓</kbd> | <kbd>↑</kbd> <kbd>↓</kbd> |
| Open or close a folder | <kbd>→</kbd> <kbd>←</kbd> | <kbd>→</kbd> <kbd>←</kbd> |
| First or last row | <kbd>Home</kbd> <kbd>End</kbd> | <kbd>Home</kbd> <kbd>End</kbd> |
| Open a document | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| Rename | <kbd>F2</kbd> | <kbd>F2</kbd> |
| The row's menu | <kbd>⇧</kbd> <kbd>F10</kbd> | <kbd>Shift</kbd> <kbd>F10</kbd> |
| [Undo](/projects/#undo) a rename, move, delete or new document | <kbd>⌘</kbd> <kbd>Z</kbd> | <kbd>Ctrl</kbd> <kbd>Z</kbd> |
| Redo | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> or <kbd>Ctrl</kbd> <kbd>Y</kbd> |
