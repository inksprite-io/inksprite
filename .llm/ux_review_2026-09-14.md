# UX review, 14 September 2026

> **Status, later the same day:** the critical finding and all ten major findings below were fixed in the commits from `fa5ca32d` to `6e0515ea` on `dev`. The minor findings are still open.

Every major flow driven end to end with Playwright on a fresh browser profile, against the dev server on branch `dev` at `112a53fa`. Desktop at 1400×900 and phone at 400×800, light and dark. No AI provider was connected, so generation itself was out of scope.

## Verdict

The writing surface is the strongest part of the app: markdown shortcuts land as you type, the plain-text view round-trips, undo works, tabs behave like an editor's, and everything left open is still open after a reload. The weakest part is what happens between projects and between the app and its provider: switching projects leaves the editor on the previous project and loses text typed there; sending with no provider stores the message and then abandons it; the settings that would fix that never say whether you are connected. Under both is an accessibility gap (rail, tree, icon buttons) that is cheap to close now.

## Findings

### Critical

- **The editor does not follow the project.** Creating a project or picking one from the list moves the URL, the tree and the chat, but the editor keeps the previous project's tabs and document. Text typed into that stale editor was found in no document afterwards. Cause: `DesktopView.vue` keys `ChatPanel` on the story id but mounts `EditorPanel` without a key, and `EditorPanel.vue` calls `useDocuments(props.storyId)` once at setup. Fix: key the editor panel on the story id; check `MobileView.vue` for the same pattern.

### Major

- **A new document is created but not opened.** From a folder menu, "New document" only starts a rename; the writer then has to find and click it. From the empty editor it opens but does not focus the editor.
- **"Keep in order" reorders the folder instead of freezing it.** A name-sorted folder jumped to creation order when ordering was switched on. Seed positions from the displayed order.
- **A summary draft is discarded on blur.** Enter and the tick save; clicking away or reloading drops the draft silently. Rename commits on blur, so the two inline editors disagree.
- **Block quotes grow a second pair of quotation marks.** Tailwind Typography adds curly quotes around `blockquote p`, so quoted dialogue reads `“"Light is a promise," …”`. Disable `::before`/`::after` in the typography config.
- **A message sent with no provider is stored and then abandoned.** The composer is enabled, the message lands in the chat, the setup dialog appears, and after dismissing it there is no error, no reason and no retry. Gate the composer or mark the turn failed with a retry.
- **Message hover actions overlap the message text.** The segment edit/delete icons float over the last words of the line. Reserve a gutter or fold them into the header row.
- **AI settings never say whether you are connected.** A fresh install shows a named profile, provider and model as if ready; the API key is behind an unlabelled "⋮" beside the provider. Show a connection state and an inline connect action.
- **Escape in the provider dialog closes Settings too.** One Escape took the open-dialog count from two to zero, twice.
- **The rail cannot be reached or operated from the keyboard.** Rail buttons are `<a>` with no href, role or name: skipped by Tab, inert to Enter/Space, no focus ring. The phone tab bar is built the same way. Use real buttons with `aria-label` and a focus style.
- **The document tree is mouse-only.** Rows are divs with tabindex -1 and no arrow-key movement. Use `tree`/`treeitem` with a roving tabindex.

### Minor

- New Project dialog opens with focus on Close instead of the Title field; the label sits tight under the header rule. The chat rename input opens empty with no selection.
- The three panel toggles look nearly identical and are ordered editor, chat, sidebar while the panels read sidebar, editor, chat.
- Delete copy contradicts retention: project delete says "cannot be undone" while Data settings say deleted items are kept 30 days. Document delete has no undo toast.
- Untitled documents sort first (empty title) and folders are interleaved with documents in a sorted folder.
- The sidebar truncates most titles at its default width with no tooltip.
- Chat Settings opens on the full system prompt in an auto-growing textarea; tool switches show raw identifiers (`read_document`).
- Chat list: search box shows with zero chats; import and rename give no confirmation while export does.
- Generation settings: the "Dice & Oracle memory" number input is clipped at the pane edge on desktop and phone; "Max Tokens" defaults to 0 with no hint; the profile name appears twice (dropdown and an identical text field).
- The restore confirmation uses table names ("1 aiProfiles, 1 aiProviders, and 3 more tables").
- The Settings dialog is fixed at most of the viewport height and mostly empty.
- Icon-only buttons with only `v-tooltip` have no accessible name: tree row menus, chat header import/new, all message actions, provider "+" and test, summary save/cancel. An icon-button component that labels itself would fix this once.
- Switches in Settings and Chat Settings have no associated label.
- Phone tab bar icons have no labels; the outline glyph is not self-explanatory.
- Copy and dev nits: "find us on Reddit ." (space before the full stop); a stray focus ring on the root twisty after a project delete; the editor scrollbar thumb shows on short documents because of the long bottom padding; Vercel Web Analytics reports page views from the local dev server.

## Proposed improvements, in order

1. Key the editor panel on the project (`DesktopView.vue`; check `MobileView.vue`) and add a test that switches projects and asserts the open tabs change. Fixes the only data-loss path found.
2. Handle "no provider" before the message leaves the composer: an inline connect state in the chat, a failed-turn state with retry, and a connection status line with a connect button in AI settings.
3. Fix the stacked-dialog Escape, or configure providers inline so there is no stack.
4. Open and focus a document as soon as it exists, on both creation paths.
5. Freeze the visible order when "Keep in order" is switched on.
6. Save summary drafts on blur, matching the rename field.
7. Give message actions their own space so hover never covers prose.
8. Turn off the typography theme's block-quote quotes.
9. One accessibility sweep: real buttons in the rail and mobile bar, a self-labelling icon-button component, a keyboard-navigable tree, labelled switches.
10. Align words with behaviour: delete and retention copy, the restore summary, the welcome typo, an undo toast for document deletes.
11. Layout polish: autofocus in dialogs, panel toggles ordered like the panels, wider or wrapping sidebar titles, the clipped number input, a collapsed prompt in Chat Settings, labels on the phone tab bar, a Settings dialog sized to its content.

## What works well

Markdown input rules; plain-text round trip; persistence of tabs, active tab, order, sidebar and theme across reload; tab behaviour (middle-click close, scrolling strip); undo; drag reorder with the self-drop guard; consistent empty states; complete dark mode; backup export and restore with a clear confirm and reload; chat export/import; the phone layout; the lossy-rewrite warning when switching a plain document back to a structured one.

## Flows exercised

28 flows: 20 pass, 6 partial, 2 fail (project switching; keyboard reachability). Console showed no errors beyond the two expected `ProviderNotConfiguredError` entries when sending without a provider.
